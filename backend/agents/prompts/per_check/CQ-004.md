# CQ-004 — Coverage workflow

You are remediating finding **CQ-004** ({severity}) on {repo_name}.

Add a workflow that runs the test suite with coverage on every PR. The exact
command depends on the project's stack — inspect the repo to choose the right
approach.

## Required action

1. Use `read_file` to inspect `pyproject.toml`, `package.json`, or `Cargo.toml`
   (whichever exists) to identify the project's test runner.

2. Use `write_file` to create `.github/workflows/coverage.yml` appropriate
   for the stack. Examples:

   - Python with pytest + pytest-cov:
     ```yaml
     name: Coverage
     on:
       pull_request: {{branches: ["{default_branch}"]}}
     jobs:
       coverage:
         runs-on: ubuntu-latest
         steps:
           - uses: actions/checkout@v4
           - uses: actions/setup-python@v5
             with: {{python-version: "3.12"}}
           - run: pip install -e ".[test]"
           - run: pytest --cov=. --cov-report=xml
           - uses: codecov/codecov-action@v4
             with: {{token: ${{{{ secrets.CODECOV_TOKEN }}}}}}
     ```

   - Node with jest or vitest: invoke `npm run coverage` (assume the script
     exists; if not, do not invent it — return a final message saying so).

3. Call `run_command` with `["yamllint", ".github/workflows/coverage.yml"]`.

4. Call `recipe_success_check` with `check_id="CQ-004"`.

5. Return a final message.

Allowed files only: `.github/workflows/coverage.yml`.
